# Артель

Локальный оркестратор AI-агентов. Интерфейс в духе Cursor: чаты, проекты, подагенты, живой стрим. Открывает папку на диске или клонирует репозиторий с твоего GitHub.

Исполнители за одним контрактом:

- **Claude** — подписка claude.ai / Pro / Max через `claude login` (Claude Code). Ключ API не нужен и это другой счёт.
- **Claude Code** — тот же вход, агент в каталоге проекта
- **Codex** — через ai.starimg или OpenAI
- **Cursor** — твой аккаунт Cursor через CLI `agent` / `cursor-agent` (не встроенный чат IDE)
- **Локальный режим** — если CLI ещё не подключен

## Cursor AI

Артель не встраивает вкладку Cursor. Она запускает тот же CLI, что и агент Cursor, в папке проекта.

1. Установи [Cursor CLI](https://cursor.com/docs/cli): в PowerShell `irm https://cursor.com/install.ps1 | iex`.
2. В Cursor: Command Palette → **Install 'cursor' command in PATH**.
3. В терминале: `agent login` — тот же аккаунт, что в IDE.
4. В Артели: шестерёнка → **Cursor AI** → «Сохранить и проверить». Точка должна стать зелёной.
5. В композере выбери исполнителя **Cursor** и модель (Grok 4.6, Composer 2, Sonnet 4.5…). Можно вписать любой id из Cursor.

Ключ API необязателен, если `agent login` уже есть. Список моделей в Артели — каталог id для CLI, не live-меню IDE.

## GitHub

Чтобы подтянуть свои репозитории:

1. Создай [classic PAT](https://github.com/settings/tokens/new?scopes=repo&description=Artel) с правом `repo`.
2. В Артели: шестерёнка → **GitHub** → вставь токен → **Сохранить и проверить**.
3. **Проекты → Добавить → GitHub**: «Загрузить мои репозитории» или вставь `owner/repo` / HTTPS URL.
4. Клон попадает в `Документы` (путь можно сменить в диалоге). Уже скачанная папка с `.git` просто откроется.

Публичный репозиторий можно клонировать без токена. Для приватных и списка «моих» нужен PAT. Токен лежит только в `data/artel.json` на этой машине. Нужен установленный Git.

## Claude по подписке

Ключ `ANTHROPIC_API_KEY` — это не подписка. Чтобы Артель ходила в вашего Claude:

```bash
npm install -g @anthropic-ai/claude-code
claude login
```

Войдите тем же аккаунтом, что на claude.ai. В Артели: Настройки → «Проверить подписку». Если в окружении задан `ANTHROPIC_API_KEY`, при активной подписке Артель его снимает, чтобы Claude Code не ушёл в API-биллинг.

## Запуск на Windows одним кликом

Скачай **Artel-windows-20260920d.zip**, распакуй папку `Artel` целиком в `C:\\Artel` (внутри `Artel.exe` и `app`). **Не запускай из папки AgentStores Cursor** — если exe из длинного пути, он сам перенесёт файлы в `C:\\Artel`.

Откроется **окно приложения**, не вкладка браузера. На сплэше должна быть строка **Сборка 2026-09-20d**. Первый запуск скачает Node.js (~80 МБ, нужен интернет) — на сплэше будет процент. Дальше офлайн. Выход — закрыть окно Артели.

Если зависло: закрой окна, в Диспетчере задач заверши `Artel.exe` и `node.exe`. Запусти `\u0421ервер-в-консоли.cmd` — ошибка будет видна. Лог — `artel.log` рядом с exe.

Если SmartScreen: «Подробнее» → «Выполнить в любом случае».

Нужен Node.js LTS: https://nodejs.org (галочки по умолчанию). Скачай исходники, распакуй. В папке должен быть `Artel.cmd` рядом с `package.json`. Дважды кликни **Artel.cmd** — запасной способ, если .exe не запустился.

Чтобы Claude шёл с твоей подписки:

```
npm install -g @anthropic-ai/claude-code
claude login
```

Войди аккаунтом claude.ai. В Артели: шестерёнка → **Проверить подписку**.

GitHub: шестерёнка → токен → **Проекты → Добавить**.

Ключи для Codex/Cursor задаются в панели «Настройки» или в `.env`. Для Claude подписки ключ не нужен.

```
# необязательно: это НЕ подписка claude.ai
ANTHROPIC_API_KEY=
STARIMG_API_KEY=
STARIMG_BASE_URL=https://ai.starimg.com/v1
OPENAI_API_KEY=
CURSOR_API_KEY=
GITHUB_TOKEN=
```

Без ключей и CLI приложение всё равно работает: агенты отвечают в локальном режиме, UI и дерево подагентов живые. Публичный GitHub-клон тоже можно без токена.

## Как пользоваться

1. Подключи GitHub или открой папку на диске.
2. Напиши задачу. В композере выбери агента и **модель**. Если включены подагенты — у каждого своя модель в блоке «Модели подагентов».
3. Создай своего агента на вкладке «Агенты» и тоже укажи ему модель.
4. Claude: установи Claude Code и выполни `claude login`. Codex/Cursor — своими ключами.

Продаём оркестрацию и контроль, не чужие подписки: ключи всегда клиентские.
