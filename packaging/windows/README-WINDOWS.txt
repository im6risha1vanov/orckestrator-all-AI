Артель для Windows
==================

1. Распакуй весь архив в папку, например Documents\\Artel
2. Дважды кликни Artel.exe — откроется окно с иконкой А
3. Выход — закрыть окно Артели

Первый запуск скачает Node.js (~80 МБ) в папку runtime. Дальше офлайн.
Распаковывай папку Artel целиком (Artel.exe рядом с app). Не запускай один только exe.

Не запускай из папки AgentStores Cursor — путь слишком длинный, Node.js зависает.
Скопируй папку на `C:\\Artel` или просто запусти новый Artel.exe: он сам перенесёт файлы в C:\\Artel и откроет окно оттуда.

На сплэше должна быть строка «Сборка 2026-09-20d». Если её нет — это старый exe.

Нужны Microsoft Edge или WebView2 Runtime (обычно уже есть на Windows 10/11).

Если SmartScreen спросит «неизвестный издатель» — «Подробнее» → «Выполнить в любом случае».

Если окно зависло или сервер не стартует:
1. Закрой все окна Артели.
2. Диспетчер задач → заверши Artel.exe и node.exe.
3. Запусти `\u0421ервер-в-консоли.cmd` — ошибка будет в чёрном окне.
   Либо смотри artel.log рядом с exe.
